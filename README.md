# 2025-2026-TankRobot

- FRC robot code in Java, mostly command based framework
- Using Arcade-style driving with an Xbox controller
- Hardware; tank treads,  two motors (CTRE Falcons) per side (4 total).

- Suggest, edit, create code for an FRC robot in Java with a mostly command based framework
- Uses a lot of CTRE products for motors, motor controllers, navigation (Pigeon2)
- Vision and AprilTag processing and tracking via Limelight cameras and software
